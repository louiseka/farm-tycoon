## Project Overview
**Farm Tycoon** is a React + TypeScript simulation game where users can manage a virtual farm. The game includes a dashboard, shop, farm, and statistics tab, allowing players to grow crops, raise animals, and track profits over time.

The first version includes the following gameplay features:

- **Dashboard, Shop, Farm, and Statistics tabs**  
- Buy and sell **animals and crops** through the shop  
- Daily balance paid to the user  
- Purchased animals **produce goods** after a set number of days  
- Crops **grow over time** and are ready to harvest after a set number of days  
- Profit and expenses summary available in the statistics tab  

## Technologies Used
- **React** – Component-based UI for dynamic gameplay  
- **TypeScript** – Type-safe development for maintainable code  
- **CSS** – Styling and layout

## Installation (Local Development)
To run the project locally:

```bash
# Clone the repository
git clone https://github.com/yourusername/farm-tycoon.git

# Navigate into the project directory
cd farm-tycoon

# Install dependencies
npm install

# Start the development server
npm start
```
